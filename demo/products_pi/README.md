# Pi demo products

These files are placeholders, not Pi products. They were made by
running `run_demo_pi.sh` on the laptop as a smoke test of the script,
on Nov 16, 2026. The laptop is x86_64, so the Pi script correctly
reported the architecture check as FAIL and the run was a script
test only.

Replace this directory with the products from a real run of
`run_demo_pi.sh` on the Raspberry Pi. A real Pi run writes its
products here and fills in the real capture times and the real
camera frame checks from Part B.
